Performance — Batching

Process conversations, not sentences

5 conversations, 22 sentences — without batching: 22 calls. With batching: 5 calls.

Individual calls
22 calls
one per sentence
Batched (per conversation)
5 calls
4.4× reduction in cost & latency
Performance — Word-Level Caching

The more users, the smarter it gets

Word metadata is shared globally — generated once, reused forever. Cache hit rate grows with scale.

Cache key: word lemma
feel / feels / felt / feeling→ "feel"
figure out / figured→ "figure_out"
Cache miss → generate + store
Cache hit → instant, zero cost
As SnowVoca scales, daily English words
are almost always cached.
Performance — Profile Compression

Fixed context, no matter how long you study

Python aggregation compresses the full history into a tiny fixed-size profile — context stays flat forever.

Compressed profile (always the same size):
accuracy_rate: 0.72
recent_sequence: ["O","O","X"]
weak_word_tags:
{feel:2, figure_out:1}
vs. raw episode log (grows forever):
ex_014 | feel | correct: true
ex_022 | figure_out | correct: false
ex_031 | zone_out | correct: false
... grows with every attempt
